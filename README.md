\# 🧠 MoodSense



> \*\*An AI-powered Emotion Detection and Journaling Web Application built using the MERN Stack.\*\*



MoodSense is a full-stack web application that helps users track their emotions, maintain a daily journal, and receive personalized mood-based suggestions. The project is being developed as part of my MERN Stack internship and focuses on promoting emotional well-being through technology.



\---



\## ✨ Features



\- 🔐 User Authentication (Register \& Login)

\- 📔 Daily Journal

\- ✏️ View \& Edit Journal Entries

\- 📜 Journal History

\- 📊 User Dashboard

\- 👤 User Profile

\- 😊 Emotion Detection Module

\- 💡 Personalized Mood Suggestions

\- 📱 Responsive User Interface

\## 🚀 Getting Started



\### Clone the Repository



```bash

git clone https://github.com/annubharadwaj25/MoodSense.git

```



\### Install Backend Dependencies



```bash

cd Backend

npm install

npm start

```



\### Install Frontend Dependencies



```bash

cd Frontend

npm install

npm run dev

```
